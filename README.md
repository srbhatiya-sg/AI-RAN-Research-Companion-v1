# AI-RAN-Research-Companion
Building a local AI research companion for telecom research using AnythingLLM, Ollama &amp; Qwen3.

A local AI research workflow for exploring AI-RAN and other telecom research papers.

The AI-RAN Research Companion is a hands-on experiment using AnythingLLM, Ollama, and Qwen3 to create a local AI workspace for studying technical research papers.

It is not a standalone AI application or an off-the-shelf AnythingLLM feature. The companion provides a reusable workflow, system configuration, study modes, and guidance for building a similar research environment locally.

## What can it help with?
Quickly understand a technical paper
Create an executive brief
Explore technical architecture
Identify key assumptions and challenges
Critically review research claims
Compare multiple papers
Generate structured research notes


## Technology stack
| Component       | Role                                             |
| --------------- | ------------------------------------------------ |
| **AnythingLLM** | Local document workspace and knowledge interface |
| **Ollama**      | Local LLM runtime                                |
| **Qwen3 8B**    | Language model used for the experiment           |

## Important

The repository does not contain research papers. Add papers that you have obtained directly from their original source

## Why local AI?

Running the research companion locally provides an alternative approach for working with technical and potentially sensitive documents. Documents can remain within the user's local environment rather than being uploaded to a cloud AI service.
Local models also provide an opportunity to experiment with AI-assisted research while understanding the underlying components—model, runtime, document retrieval, and workspace—rather than treating AI as a black box.
Local execution does not automatically guarantee security or confidentiality. Users should understand their own device, software, model, and data-security configuration before working with sensitive information
